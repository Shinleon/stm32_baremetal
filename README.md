## Project Outline  
### Memory outline
If we look in section *2.4 Embedded SRAM* of the Reference Manual for the `STM32L47xxx`,  we see that the STM32L47x has 96 Kbytes SRAM1 and 32 Kbytes SRAM2; there is also 1 MB Flash memory, shown in *2.1 System Architecture* **Figure 1**. Looking at **Figure 3** in section *2.2.2 Memory map and register boundary addresses*, we can see that Flash memory is in the range [`0x0800_0000`, `0x0810_0000`), and SRAM1 is in the range of [`0x2000_0000`, `0x2001_8000`).    

### Memory registers for on board LED  
We need to look at the Reference Manual to determine which registers in the chip are important.  The LED we wish to flip is controlled by GPIO, which is in Advance High Performance Bus 2 (AHB2). We need to activate the clock for the pin, controlled by Reset and Clock Control (RCC) module; set the relevant pin for the LED to output mode, and write application code to then toggle the pin on an interval.

#### **Reference Manual resource**  
Section `2.2.2`, specifically at table 1, we can see the *AHB2* and *AHB1* offsets for GPIOA and RCC; RCC is in AHB1, while the GPIO is in AHB2.    
Section `6.4.17` has AHB2 Peripheral clock enable register (RCC_AHB2ENR).    
Section `8.5.1` outlines mode register (GPIOx_MODER).  
Section `8.5.2` outlines register push-pull or open drain (GPIO_OTYPER).  
Section `8.5.6` outlines output data register, where we can set the values of the output for gpio pins.

#### **Datasheet resource**
According to Table 19 in the STM32L476xx Datasheet, *Peripherals* start at `0x4000_0000`; there are two AHB1 sections and two AHB2 sections in the location called *Peripherals*, so I am going to call one AHBx_upper and one AHBx_lower, to differentiate between the two. {AHB1_UPPER: [0x4002_0000, 0x4002_4400), AHB1_LOWER: [0x4000_0000, 0x4000_99800), AHB2_UPPER: [0x4800_0000, 0x5006_0C00), AHB2_LOWER: [0x4001_0000, 0x4001_6400)}.  AHB2_upper's start address is 128MB after *Peripherals* start location, at `0x4800_0000`; GPIOA starts at the beginning of AHB2_upper, at the same address, and goes until `0x4800_03FF`; alternatively viewed, GPIOA is 1Kb (1024 bytes) in length.  
RCC is located in AHB1_upper, with a start address offset 0x1000 or 4096bytes(4KB) from AHB1_Base, and AHB1_BASE is at 0x4002_0000, offset 80KB from *Peripherals* start location(0x4000_0000).  

Using all the above information, we can create the following `#define`s.  

```
PERIPHERAL_BASE (0X4000_0000U)

// AHB1 upper
AHB1_UPPER_OFFSET (0x0002_0000U)
AHB1_UPPER_BASE (PERIPHERAL_BASE + AHB1_UPPER_OFFSET)

// AHB2 upper
AHB2_UPPER_OFFSET (0x0800_0000U)
AHB2_UPPER_BASE (PERIPHERAL_BASE + AHB2_UPPER_OFFSET)

// GPIO, located in AHB2 upper
GPIOA_OFFSET (0x0U)
GPIOA_BASE (AHB2_UPPER_BASE + GPIOA_OFFSET)

// RCC, located in AHB1 upper
RCC_OFFSET (0x1000U)
RCC_BASE (AHB1_UPPER_BASE + RCC_OFFSET)

// RCC periph clock enable register, for GPIO A (0: disabled, 1:enabled)
RCC_AHB2ENR_OFFSET (0x4CU)
RCC_AHB2ENR (RCC_BASE + RCC_AHB2ENR_OFFSET)
RCC_AHB2ENR_GPIOAEN (0x0U)

// GPIO port mode registers
GPIO_MODER_OFFSET (0x0U)
GPIOA_MODER (GPIO_BASE + GPIO_MODER_OFFSET)
GPIO_MODER_MODER5 (10U)

// GPIO output data register (read/write to pin)
GPIO_ODR_OFFSET (0x14U)
GPIOA_ODR (GPIO_BASE + GPIO_ODR_OFFSET)

LED_PIN (5)
```
